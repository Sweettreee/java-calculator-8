## **기능**

+ 입력 받기 기능
    + 계산기에 사용할 문자열을 입력받는다.

+ 구분자를 정의하는 기능
    + 커스텀 구분자와 기본 구분자(',' ':')를 앞으로 구분자로 사용할 것이라고 정의

+ 숫자를 추출하는 기능
    + 구분자를 기준으로 숫자를 추출해 저장한다

+ 계산하는 기능
    + 추출한 숫자로 실제 계산을 진행한다. 예상되지 않은 입력값에 대한 예외처리를 진행합니다.
+ 출력하는 기능
    + 결과를 출력
